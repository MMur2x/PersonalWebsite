Things I've built

Personal projects where I get to choose the whole stack.

  1. Deadline Cay

    Homework Tracker Extension

    Sep 2026 to present

    A Chrome extension that brings Canvas assignments to life. It syncs automatically the moment you submit work, so there's no manual refresh, and lays every due date, exam and deadline out on an interactive calendar with day-by-day detail views and custom notes.

    • Real-time Canvas sync
    • 5 views
    • Every enrolled class tracked
    • Built on Manifest V3 with a background service worker that detects Canvas activity in real time and syncs on a user-chosen interval.
    • Color-codes each day by urgency and tracks completion across all enrolled classes with a progress ring.
    • Light and dark themes, plus a side-panel mode so it stays open while you work.
    • JavaScript
    • Chrome MV3
    • Service Workers
    • Canvas API

  3. Shipwright's Rest

    Personal Portfolio Website

    Summer 2025, redesigned 2026

    This site. Built from scratch with a custom CSS design system, day and night theming and scroll-driven animation, version-controlled with Git and deployed on GitHub Pages.

    • No framework
    • No build step
    • Reduced motion respected
    • Every color, space and shadow is a design token, so the whole site re-skins from one block of CSS.
    • The route, the Going Merry, the devil fruits and the Haki controls are vanilla JavaScript and hand-drawn SVG, with no dependencies.
    • Motion ideas adapted from the Motion Primitives kit (Tilt, Spotlight, Border Trail, Magnetic, Text Effect), rewritten without React so the site stays build-free.
    • Button and divider backgrounds are SVGs generated in the style of Haikei: layered waves and blob scenes.
    • HTML
    • CSS
    • JavaScript
