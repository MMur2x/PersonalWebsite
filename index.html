Homework Tracker Extension

Sep 2026 to present

A Chrome extension that brings Canvas assignments to life. It syncs the moment you submit work, so there’s no manual refresh, and lays every due date, exam and deadline out on an interactive calendar.

  • Built on Manifest V3 with a background service worker that detects Canvas activity in real time.
  • Color-codes each day by urgency and tracks completion across every enrolled class with a progress ring.
  • Light and dark themes, plus a side-panel mode so it stays open while you work.
  • JavaScript
  • Chrome MV3
  • Service Workers
  • Canvas API
